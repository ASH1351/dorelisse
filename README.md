# DORÈLISSE PARIS — Haute Skincare & Luxury Beauty

An ultra-elegant, mobile-responsive single-page experience for **Dorèlisse Paris**, a Parisian luxury beauty and skincare house delivering visible glow, care, confidence, and results in just 1 week using 100% chemical-free formulations.

---

## ✨ Features & Architecture

1. **Preloader Animation:** The Dorèlisse signature gold teardrop gracefully draws and fills with metallic gold before revealing the Maison crest.
2. **Sticky Glass-Blur Navbar:** Fluid responsive navigation with active section spying, live shopping bag counter, and full-screen mobile menu.
3. **Cinematic Hero:** Satin cream textures, gentle floating hero serum bottle with golden aura glow, floating gold particles (60fps HTML5 Canvas), and trust strip.
4. **Brand Promise (3 Pillars):** Luminous cards for *Glow*, *Care*, and *Confidence* with gold hairline accents.
5. **Featured Collection (6 Products):**
   - *L'Élixir Sublime Serum* (€145)
   - *Crème Céleste Day Velvet* (€125)
   - *Baume Nocturne Recovery* (€135)
   - *Gelée Purifiante Cleanser* (€75)
   - *Regard Précieux Eye Nectar* (€95)
   - *Brume Florale Hydrating Veil* (€65)
   - Features real-time "Add to Bag", shimmer sweep effect, and Quick View modal.
6. **Pure By Nature (Chemical-Free Section):** Free-from pill badges (zero parabens, sulfates, silicones, fragrances) and circular gold-ringed ingredient macros (Vitamin C, Hyaluronic Acid, Rose Extract, 24K Gold Peptides).
7. **The 7-Day Glow Journey:** Animated vertical timeline with dynamic gold SVG progress line that fills as you scroll through Days 1, 3, 5, and 7.
8. **Before & After Results:** Interactive draggable touch & mouse comparison slider with matching Day 1 vs. Day 7 portrait imagery and animated clinical counters (94%, 97%, 100%).
9. **Your Daily Ritual:** 3-step mindful Parisian routine (*Cleanse → Treat → Glow*) with architectural arch-framed visuals.
10. **Testimonials Slider:** Client reviews with 5 gold stars, customer avatars, swipe gestures, and autoplay.
11. **Why Dorèlisse Strip:** 5 luxury badges (Parisian Craftsmanship, Clean Formulas, Cruelty Free, Recyclable Luxe Glass, Complimentary Shipping).
12. **Special Offer Banner:** "Join the Circle" newsletter input with instant confirmation toast and 10% privilege discount code.
13. **Haute Parisian Footer:** Place Vendôme address, concierge email and phone, social links, payment methods, and copyright.
14. **Interactive Shopping Bag Drawer:** Slide-over cart with live quantities, price calculations, and free Paris shipping progress bar.
15. **Floating WhatsApp Conseiller:** One-click direct link to personal skincare consultation.
16. **Custom Desktop Cursor Glow:** Fluid radial gold glow following the mouse pointer.

## 🚀 Quick Start

Simply open `index.html` in any web browser, or launch with any local static server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Then visit `http://localhost:3000`.
